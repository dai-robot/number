# 秒トリビア イベントデータ仕様書

> バージョン: 2.0  
> 対象アプリ: Next.js 版「秒トリビア」  
> 企画仕様: [PLANNING_SPEC_v2.md](./PLANNING_SPEC_v2.md)  
> 進捗管理: [SLOT_PROGRESS.md](./SLOT_PROGRESS.md)

**目的**: 「数字の世界を発見するゲーム」として、301件すべてを **誰かに話したくなる当たり枠** にする。補完・ごまかしは禁止。

---

## 1. 概要

| 項目 | 値 |
|------|-----|
| コンセプト | 知的ガチャ（勉強アプリでも雑学図鑑でもない） |
| 利用秒数 | `0.00` 〜 `30.00` |
| 表示精度 | **0.01秒**（例: 3.14 / 7.77 / 22.22） |
| 内部スロット | **0.1秒刻み**（例: 3.1 / 3.2 / 7.7） |
| イベント数 | **301件**（0.0〜30.0、重複・欠損なし） |
| 近似一致 | ±`0.03` 秒（例: 3.12 → 3.1 円周率で Near） |
| ハズレ枠 | **なし**（301件すべてが当たり品質） |

---

## 2. 絶対ルール（禁止事項）

### 2.1 禁止パターン

| ID | 禁止内容 | 悪い例（v2 NG） |
|----|----------|------------------|
| F01 | 空きスロットの自動テンプレ補完 | `「3.14秒。数学的に意味のある秒数。」` |
| F02 | 記念日の機械生成 | 存在しない日付の推定 |
| F03 | 数値だけのプレースホルダー | `「12.3秒のレコード」` |
| F04 | 世紀・時代だけの曖昧記述 | `「19世紀の歴史。」` |
| F05 | 無関係な年号の秒数帯混入 | 22.5秒 → 1935年アシモフ |
| F06 | 同一公式の量産 | 全スロット `ボルトペースでX秒走るとYm` |
| F07 | 根拠薄弱な「近似」「スケール」「近辺」 | `「ISOコード124のスケール」` |
| F08 | 検証不能・出典不明 | 創作話 |
| F09 | **秒数→年の機械当て** | 22.4秒だから224年前 |
| F10 | **秒数→元素番号の機械当て** | 13.8秒だから138番元素 |
| F11 | **秒数→年号出来事の機械当て** | 18.2秒だから182年の出来事 |
| F12 | Wikipediaコピペ調 | 百科事典の段落そのまま |

### 2.2 OK 例（v2 準拠）

| スロット | イベント | 関係の説明 |
|----------|----------|------------|
| 3.1 | 円周率 π | 3.14の近似 |
| 7.7 | 七夕 | 7月7日 |
| 9.6 | ボルト100m WR | 9.58秒 |
| 8.8 | エベレスト | 標高8848m |

**選定基準**: 「誰かに話したくなる」＋数字との関係を description で説明できる。

## 5. データスキーマ

```typescript
interface Trivia {
  value: number;        // 0.0〜30.0（0.1刻み）
  title: string;
  description: string;  // 具体・検証可能・関係を説明
  category: TriviaCategory;
  rarity: TriviaRarity;
  sourceType: TriviaSourceType;
  shortTitle?: string;  // Near 表示用（例: 「円周率」）
}
```

### 品質チェックリスト（全301件）

- [ ] 検証可能
- [ ] 具体的（誰・いつ・記録値）
- [ ] 数字との関係を説明可能
- [ ] 子供でも理解できる
- [ ] 大人も「へえ」と思える
- [ ] F01〜F12 に該当しない

## 6. 数値判定フロー

```
ユーザー STOP
  → 表示: round(秒, 2)  … 0.01精度（3.14）
  → 判定: clamp(秒, 0, 30)
  → exact: trivia.value === stoppedAt
  → near:  |stoppedAt - value| ≤ 0.03 かつ > 0
  → miss:  最接近を表示（ハズレ枠ではなく「あとX秒で〇〇」）
```

| 表示 | 判定 | 結果例 |
|------|------|--------|
| 3.14 | near | あと0.04秒で円周率！（3.1スロット） |
| 3.12 | near | あと0.02秒で円周率！ |
| 9.58 | near | ほぼボルト記録！（9.6スロット） |
| 30.50 | clamp→30.0 | 30.0スロット（CM30秒等） |

## 7. 歴史・年号の扱い

| 方針 | 詳細 |
|------|------|
| **0.0〜30.0 には年号を入れない** | 秒数帯と無関係な歴史は禁止 |
| 歴史40件 | 月面着陸・ベルリンの壁など **秒数と説明可能な** 事実のみ |
| 無理な年号当て | F09〜F11 で禁止 |

## 8. ビルド・検証（現状と改修方針）

### 現状（要改修）

```
scripts/
  build-trivia-1000.js    # TARGET=1000（699件は未使用）
  generate-slot-fill.js   # 自動補完あり → 廃止
  slot-fill.js            # 薄い記述多数 → 廃止
  range-19-31.js          # 公式量産 → 手書き差し替え
```

### 改修後（推奨）

```
scripts/
  build-trivia.js         # TARGET=301 のみ
  validate-facts.js     # F01〜F12 禁止パターン検出
  validate-logic.js     # 一致・範囲検証
  data/slots/           # 手書き301件（レンジ別）
```

```bash
npm run validate-facts   # 品質（新設予定）
npm run validate-logic   # ロジック
npm run generate-trivia  # ビルド（手書きのみ）
npm run build
```

## 11. 用語集

| 用語 | 意味 |
|------|------|
| スロット | value 1つ＝0.1秒刻みの固定席 |
| 当たり枠 | 301件すべて。ハズレ用の薄いイベントは作らない |
| 補完 | 空きをテンプレで埋めること（**禁止**） |
| Near | 0.01表示と0.1スロットの橋渡し（±0.03秒） |
