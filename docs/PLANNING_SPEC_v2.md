# 秒トリビア 企画仕様書 v2.0

## コンセプト

「秒数を止めるゲーム」ではなく、

**"数字の世界を発見するゲーム"**

を目指す。

ユーザーはストップウォッチを止めるだけで、
その数字に紐づく面白い事実・記録・発見・歴史を知ることができる。

目標は

* 勉強アプリではない
* 雑学アプリでもない
* SNS映えする知識図鑑でもない

その中間の

**「ついもう一回押したくなる知的ガチャ」**

を作ること。

---

## ゲーム体験

### 理想的な反応

* 「へえ！」
* 「知らなかった」
* 「子供に話したい」
* 「もう一回やる」
* 「円周率狙いたい」
* 「コンプリートしたい」

### 避けるべき反応

* 「無理やり感がある」
* 「意味がわからない」
* 「Wikipediaのコピペ」
* 「数字との関係が薄い」

---

## 基本ルール

### タイマー

```
開始 → 0.00秒〜30.00秒 → STOP → 結果表示
```

---

## 数値判定

| 層 | 精度 | 例 |
|----|------|-----|
| 表示 | 0.01秒 | 3.14 / 7.77 / 22.22 |
| 内部スロット | 0.1秒刻み | 3.1 / 3.2 / 3.3 |

**合計 301スロット**（0.0〜30.0）

---

## 重要方針

### 301スロット全てにイベントを配置

ただし **空きを埋めるためのイベントは NG**。

#### NG 例

* 22.4秒だから224年前
* 13.8秒だから138番元素
* 18.2秒だから182年の出来事

#### OK 例

| スロット | 内容 | 根拠 |
|----------|------|------|
| 3.1 | 円周率 π | 3.14の近似 |
| 7.7 | 七夕 | 7月7日 |
| 9.6 | ボルト100m世界記録 | 9.58秒 |
| 8.8 | エベレスト | 8848m |

---

## 品質基準

### 必須

* 検証可能
* 具体的
* 数字との関係を説明可能
* 子供でも理解できる
* 大人も「へえ」と思える

### 禁止

* 自動生成埋め
* 世紀テンプレ
* 年号テンプレ
* 意味のない語呂
* 根拠不明
* Wikipediaコピペ
