# 秒の物語

止めた秒に、短い人生が出る。

スマホで開いてすぐ遊べる、ストップウォッチ型の超短編小説アプリです。

## アプリ概要

1. `START` を押す
2. 好きな瞬間に `STOP` を押す
3. 実際に止まった秒数を表示する
4. その秒数に対応した「◯秒の物語」を表示する
5. `Xでシェア` または `画像保存` でSNSに共有する

## 秒数ロジック

- ストップウォッチ範囲は `0.00` 〜 `30.00` 秒
- 表示は小数点2桁
- 物語は `1秒` 〜 `30秒` の30本
- 実際に止まった秒数 `stoppedSeconds` を四捨五入して `storySecond` を決める
- `storySecond` は `1` 〜 `30` に clamp する

例:

- `0.32秒` → `1秒の物語`
- `1.49秒` → `1秒の物語`
- `1.50秒` → `2秒の物語`
- `7.42秒` → `7秒の物語`
- `7.51秒` → `8秒の物語`
- `30.00秒` → `30秒の物語`

## ストーリーデータの追加方法

ストーリーデータは `src/data/stories.ts` にあります。

各データは以下の形式です。

```ts
{
  second: 1,
  category: "恋愛",
  tone: "切ない",
  story: [
    "本文1行目",
    "本文2行目",
    "本文3行目",
    "本文4行目"
  ],
  shareText: "シェア画像や補足表示に使う短い一文"
}
```

本文はアプリの核なので、追加・修正時は勝手にリライトせず、原稿どおりに登録してください。

## 既読と物語図鑑

読んだ秒の物語は `localStorage` に保存されます。

トップ画面には以下のように達成率を表示します。

```txt
物語図鑑
7 / 30
23%
```

## 画像保存

結果画面の `画像保存` から、SNS向けの縦長画像を生成できます。

- サイズ: `1080 x 1920`
- 内容: 秒数、物語本文、アプリ名「秒の物語」、URL
