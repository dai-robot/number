# 秒の物語

止めた秒に、短い人生が出る。

## 概要

ストップウォッチを止めた秒数に応じて、1秒〜30秒の超短編ストーリーが表示されるスマホ向けアプリです。

1. `START` を押す
2. 好きな瞬間に `STOP` を押す
3. 実際に止まった秒数を表示する
4. その秒数に対応した「◯秒の物語」を表示する
5. `Xでシェア` または `画像保存` でSNSに共有する

## 秒数ロジック

STOP時の秒数を四捨五入し、1〜30秒に変換します。

```ts
const storySecond = Math.min(30, Math.max(1, Math.round(stoppedSeconds)));
```

例:

- `0.32秒` → `1秒の物語`
- `1.49秒` → `1秒の物語`
- `1.50秒` → `2秒の物語`
- `7.42秒` → `7秒の物語`
- `7.51秒` → `8秒の物語`
- `30.00秒` → `30秒の物語`

## ストーリーデータの追加方法

ストーリーデータは `src/data/stories.ts` にあります。

各データは以下の形式です。

```ts
{
  second: 1,
  band: "impact",
  category: "恋愛",
  tone: "切ない",
  story: [
    "本文1行目",
    "本文2行目",
    "本文3行目",
    "本文4行目"
  ],
  shareText: "シェア画像や補足表示に使う短い一文"
}
```

重要:
ストーリー本文は勝手に変更しないでください。

## 既読と物語図鑑

読んだ秒の物語は `localStorage` に保存されます。

トップ画面には以下のように達成率を表示します。

```txt
物語図鑑
7 / 30
23%
```

## 画像保存

結果画面の `画像保存` から、SNS向けの縦長画像を生成できます。

- サイズ: `1080 x 1920`
- 内容: 秒数、物語本文、アプリ名「秒の物語」、URL

## テスト

```bash
npm run validate-stories
npm run build
```
